Read fixed substepping configuration from file and construct a proper range ptr\+\_\+range from user\textquotesingle{}s input. 

The file input follows convention\+: only the boundaries of the increments are given. Example\+: \mbox{[}0.\+1, 0.\+5, 0.\+9\mbox{]}. On the other hand, ptr\+\_\+range must contain also 0.\+0 at the beginning and 1.\+0 at the end. So, the range from in the earlier example would be\+: \mbox{[}0.\+0, 0.\+1, 0.\+5, 0.\+9, 1.\+0\mbox{]}. This function ensures that a proper range is constructed from user\textquotesingle{}s input.
