
Procedure: How to extract SMT data from .C file

I. Prequisities

 - The programs form MTM-FHM bundle:      printc.exe,  rottex.exe,  odflam.exe
 - Datafiles: WAGNER.B04  CREATE6.B01 CREATE6.B02

Hereafer we will assume that input texture file is named "input.C"  This is a binary file file that contains C-coefficients.

II. Execution

1) Check the class of symmetry:

Issue the following command:

printc.exe input.C

The program will produce file "printc.L01". The second line of that file contains information about class of symmetry - see Table 1 in MTM-FHT manual. 
Check if that line contains  IMAG=2  and IDN=1, which  means the Class F is used (triclinic, no sample symmetry). 
If so, then go to point 3 of the procedure, otherwise proceed step 2.

2) Impose triclinic symmetry (Class F):

Prepare file rottex.i01. It should contain:

00.0        00.0      00.00               PHI1/PHI/PHI2
    2    1                                IMPOSED IMAG, IMPOSED IDN
inputF.triclinic

The last line is the comment that will be placed in new .C file.

Issue command:

rottex.exe rottex.i01 rottex.l01 WAGNER.B04 input.C inputF.C

Verify if the sample symmetry is correct:

printc.exe inputF.C

The program will produce printc.L01 file that should contain IMAG=2  and IDN=1 in the second line.

3) Transform .C file into AODF format:

Create file  pltodf_c.i01. It should contain:
   0                    IEVOD: if =0: Ordinary case
                               if =1: Only ODD part of the ODF
                               if =2: Only EVEN part of the ODF

Issue the command:

calcodf.exe pltodf_c.i01 CREATE6.B01 CREATE6.B02 inputF.C inputF.001


4) Extract output SMT file from AODF format:

Create file odflam.i01. It should contain one line that specifies the number of orientations to extract:

5000           Number of Selectors (Max. 12996)

Issue the command:

odflam.exe odflam.i01 odflam.l01 output.smt output.tx0 inputF.001

The program will produce output file output.smt
