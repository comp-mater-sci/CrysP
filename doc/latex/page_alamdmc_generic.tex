Generic configuration settings are applicable to all Alam\+DMC modules. As described in \mbox{\hyperlink{page_alamdmc_format_alamdmc_format_basics}{Basic Formatting rules}}, these settings are located in the leading part of the configuration file. It has its own internal structure, consisting of three main sections, as follows\+: 
\begin{DoxyEnumerate}
\item \mbox{\hyperlink{page_alamdmc_generic_config_outputs}{Configuration of outputs}}  
\item \mbox{\hyperlink{page_alamdmc_generic_config_multiscale}{Configuration of the multi-\/scale model}}

\end{DoxyEnumerate}\hypertarget{page_alamdmc_generic_config_outputs}{}\doxysection{Configuration of outputs}\label{page_alamdmc_generic_config_outputs}
The outputs of the program are controlled by three parameters\+:
\begin{DoxyEnumerate}
\item \textbackslash{}confdef\{output\+\_\+prefix,path\} is a prefix for the output files generated by the program.
\item \textbackslash{}confdef\{state\+\_\+request,logical\} specifies whether the program incrementally writes out the material state variables on every deformation step. If \textbackslash{}conffield\{state\+\_\+request\} is {\ttfamily True}, the program will also write the initial state of the material. The texture data will be written to the file \textbackslash{}conffield\{output\+\_\+prefix\}.CUR. Other outputs may vary depending on the model selected.
\item \textbackslash{}confdef\{verbosity,integer\} controls amount of print-\/outs sent to the standard output (the terminal). The value can vary from 0 (zero) for a minimalistic output to 4 (four) for very detailed print-\/outs about the calculations being performed by the program.
\end{DoxyEnumerate}

\item {\ttfamily 1}\label{page_alamdmc_generic_hardening_model1}%
\Hypertarget{page_alamdmc_generic_hardening_model1}%
~\newline
 for Voce-\/type of isotropic hardening. If this hardening law is chosen, it is followed by suboption specifying the parameters of Voce hardening law\+:
\begin{DoxyEnumerate}
\item \textbackslash{}confdef\{voce\+\_\+parameters,realarray\} contains 5 parameter values that are ordered as\+: $ \tau_0 \space \tau^{III}_{sat} \space \tau^{IV}_{sat} \space \theta_0 \space \theta_T $.
\end{DoxyEnumerate}

The classical Voce hardening law assumes that the hardening rate $ \theta=\frac{d\tau}{d\gamma} $ decreases linearly as a function of $ \tau $. Current implementation is more generic\+: besides such {\itshape one-\/stage} hardening behavior, also {\itshape two-\/stage} hardening behaviour is supported. The two subsequent hardening stages are denoted stages {\ttfamily III} and {\ttfamily IV}, respectively. In $ \tau-\theta$-\/diagram, the two-\/stage hardening behavior shows 2 linear parts, connected to each other at a so-\/called transition point. The physical meaning of the Voce input parameters is as follows\+: $ \tau_0 $ is the initial flow stress (i.\+e. of the stage {\ttfamily III}), $ \tau^{III}_{sat} $ is the saturation flow stress associated to stage {\ttfamily III}, $ \tau^{IV}_{sat} $ is the saturation flow stress associated to stage {\ttfamily IV}, $ \theta_0 $ is the initial hardening rate (i.\+e. of the stage {\ttfamily III}), and $ \theta_T $ is the hardening rate of the transition point between stages {\ttfamily III} and {\ttfamily IV}. The input parameters are subject to the constraints $ 0 < \tau_0 < \tau^{III}_{sat} \leq \tau^{IV}_{sat} $ and $ 0 < \theta_T < \theta_0 $. The one-\/stage Voce variant is retrieved by imposing $ \tau^{III}_{sat} = \tau^{IV}_{sat} $ and setting $ \theta_T $ to an arbitrary value within constraint boundaries. The two-\/stage Voce hardening law is given by\+: \[ \begin{split} & \tau = \tau^{III}_{sat} - (\tau^{III}_{sat}-\tau_0) \exp{\left( \frac{-\theta_0}{\tau^{III}_{sat}-\tau_0}\gamma \right)} \quad \textrm{for} \quad \gamma\leq\gamma_T \\ & \tau = \tau^{IV}_{sat} - (\tau^{IV}_{sat}-\tau_T) \exp{\left( \frac{-\theta_T}{\tau^{IV}_{sat}-\tau_T}(\gamma-\gamma_T) \right)} \quad \textrm{for} \quad \gamma\geq\gamma_T \end{split} \] ~\newline
 Here, $ \gamma_T $ and $ \tau_T $ are two dependent Voce parameters that denote the accumulated slip and the flow stress at the transition point, respectively.

\end{DoxyEnumerate}\hypertarget{page_alamdmc_generic_config_search_procedure}{}\doxysection{Configuration of the search procedure}\label{page_alamdmc_generic_config_search_procedure}
This part of the configuration file controls how the program will search for the strain rate that corresponds to a requested stress state. A gradient-\/based Trust Region (TR) least squares solver is used to find the strain rate $ A^\star $ that corresponds to the stress $ S^\star $\+: \[ A^\star = \mathrm{arg min} \left\| \frac{S(A)}{\| S(A) \|} - \frac{ S^\star }{ \| S^\star \| } \right\| \] To minimize the objective function, the TR solver requires its Jacobian. The Jacobian matrix is numerically approximated by the finite difference method.


\begin{DoxyEnumerate}
\item \textbackslash{}confdef\{solver\+\_\+default,logical\} specifies if default values for solver settings should be used. If \textbackslash{}conffield\{solver\+\_\+default\} is\+:
\begin{DoxyItemize}
\item {\ttfamily False} then the subsequent lines provide the following suboptions\+:
\begin{DoxyEnumerate}
\item \textbackslash{}confdef\{jacobian\+\_\+fd\+\_\+step,real\} controls how the Jacobian is constructed. The field \textbackslash{}conffield\{jacobian\+\_\+fd\+\_\+step\} specifies the length of strain increment that is used for estimating the Jacobian by finite difference method.
\item \textbackslash{}confdef\{search\+\_\+linearize,logical\} specifies whether the program should first attempt to solve the minimization problem that is considered linear. Note that if the \textbackslash{}conffield\{search\+\_\+linearize\} is set to {\ttfamily True} (which is the default), then the linearization is attempted each case in which strain rate corresponding to a given stress is sought, and also per strain increment, provided that strain evolution is computed. If the solver fails to find a good quality solution of the linearized problem, it will fall back to the non-\/linear problem. The non-\/linear problem is much more computationally expensive, since it requires several recalculations of the Jacobian matrix. Therefore, the user is advised to use \textbackslash{}conffield\{search\+\_\+linearize\} set to {\ttfamily True} whenever possible. The linearized problem can be solved much faster and in practice its solution rarely differs from the solution of its non-\/linear counterpart.
\item \textbackslash{}confdef\{TR\+\_\+default\+\_\+epsilon,real\} and \textbackslash{}confdef\{TR\+\_\+objective\+\_\+norm,real\} control convergence criteria used by the solver. The search for the minimum is considered successful if the square norm of the objective function does not exceed \textbackslash{}conffield\{TR\+\_\+objective\+\_\+norm\}. In most cases, setting \textbackslash{}conffield\{TR\+\_\+objective\+\_\+norm\} to $ 10^{-3} $ is sufficient to reach a good convergence.
\item \textbackslash{}confdef\{solver\+\_\+advanced,logical\} specifies if advanced solver settings should be read. This unlocks a multi-\/line option, which currently remains undocumented.
\end{DoxyEnumerate}
\item {\ttfamily True} there are no suboptions.
\end{DoxyItemize}
\end{DoxyEnumerate}

\end{DoxyNote}
