\doxysubsection{Detailed Description}
Data structure for parsing (and combining) the command line arguments. 

The structure and the procedures provided support a concept of a \char`\"{}command argument\char`\"{} in the command line, which acts as a selector of the run mode (or subprogram). The \char`\"{}command argument\char`\"{} shall be looked up in the command map (an instance of Linear\+Map). However, the library does not force using \char`\"{}command argument\char`\"{} in the code.

\begin{DoxyNote}{Note}
The command line interface is very crude at the moment. There is no actual need to improve it much because any complicated use case shall be served by a \char`\"{}pythonized\char`\"{} interface... 
\end{DoxyNote}
