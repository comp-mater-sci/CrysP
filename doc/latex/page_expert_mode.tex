\hypertarget{page_expert_mode_autotoc_md35}{}\doxysubsection{Overview}\label{page_expert_mode_autotoc_md35}
In the {\itshape expert mode} you use the engine of the VEF\+: the Alam\+DMC program, which contains a number of different modules for virtual mechanical testing and material characterization on the basis of multi-\/scale crystal plasticity ~\newline
 models such as the Full Constraint (FC) Taylor model and the Alamel model. The Alam\+DMC enables to perform {\bfseries{stress-\/driven}} analysis on {\bfseries{strain-\/rate driven}} multi-\/scale models through numerical inversion of the multi-\/scale model in an \mbox{[}iterative procedure\mbox{]} (\mbox{\hyperlink{page_alamdmc_generic_config_search_procedure}{Configuration of the search procedure}}).

From this part of the user manual you will learn how to set up and interpret virtual experiments in Alam\+DMC. More in detail\+:
\begin{DoxyItemize}
\item \mbox{\hyperlink{page_alamdmc_usage}{Alam\+DMC Usage}} tells you how to execute the Alam\+DMC program.
\item \mbox{\hyperlink{page_alamdmc_format}{Alam\+DMC Configuration File Format}} discusses the formatting to be used in Alam\+DMC configuration files.
\item \mbox{\hyperlink{page_alamdmc_generic}{Alam\+DMC Generic Configuration}} explains in detail the configuration settings that are applicable to all Alam\+DMC modules.
\item \mbox{\hyperlink{page_alamdmc_modules}{Alam\+DMC Modules}} documents the configuration of individual Alam\+DMC modules. It also describes the module-\/specific outputs generated. 
\end{DoxyItemize}
