\doxysubsection{Detailed Description}
Provides object factory for range types from the cri\+Range module. 

The module also defines named constants for the known types of ranges. \begin{DoxyRemark}{Remarks}
This module is not available in the builds with old compilers (such as Intel Fortran 11.\+1) 
\end{DoxyRemark}
