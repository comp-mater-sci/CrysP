\doxysubsection{Detailed Description}
nlls\+TR -- wrapper module for MKL Non-\/\+Linear Least Squares Trust Region algorithm 

\begin{DoxyRemark}{Remarks}
The module can be compiled with\+: ifort \texorpdfstring{$>$}{>}= 12.\+1, gfortran \texorpdfstring{$>$}{>}= 4.\+6. Earlier versions are unable to handle OO technique in a proper way or simply fail at compilation time. 
\end{DoxyRemark}
