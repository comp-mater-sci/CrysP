{\footnotesize\ttfamily logical nllstr\+::nllstrconf\+::constjacobi = .false.}



Helper for problems with invariant Jacobi matrix. 

If this variable is set to .true., the library will assume that Jacobi matrix is constant over subsequent steps. As effect, the matrix will be evaluated only once, before the first step of optimization procedure. This parameter is useful if the optimization problem is linear or can be linearized. \mbox{\Hypertarget{structnllstr_1_1nllstrconf_ae089f28ec465a3e2b70318665cfeb500}\label{structnllstr_1_1nllstrconf_ae089f28ec465a3e2b70318665cfeb500}}
