The {\ttfamily vef\+\_\+datacard} tool calculates typical yield points used in calibration of advanced yield loci. It provides the output in inter-\/operable formats (JSON, CSV). \begin{DoxyVerb}usage: vef_datacard [-h] [--jobname JOBNAME] --input INPUT
                    [--cpmodel {ALAMEL,FCTaylor}] --structure {fcc,bcc}
                    [--uniaxial UNIAXIAL [UNIAXIAL ...]] [--equibiaxial]
                    [--inplane sigma_xx sigma_yy sigma_xy]
                    [--arbitrary sigma_xx sigma_yy sigma_zz sigma_xy sigma_yz sigma_xz]
                    [--yld theta_begin theta_end theta_step] [--version]
                    [--serial] [--intermediate_dir directory_path]

Calculate datacard for yield locus calibration The purpose of the tool is to
calculate at once various yield points typically used in calibration of
advanced yield locus models.

optional arguments:
  -h, --help            show this help message and exit
  --jobname JOBNAME     Name to be used as prefix of the output files
  --input INPUT         Texture file
  --cpmodel {ALAMEL,FCTaylor}
                        Crystal plasticity model to be used
  --structure {fcc,bcc}
  --uniaxial UNIAXIAL [UNIAXIAL ...]
                        Directions of uniaxial tension tests
  --equibiaxial         Evaluate equibiaxial tension point
  --inplane sigma_xx sigma_yy sigma_xy
                        Evaluate in-plane stress point givend by: sigma_xx
                        sigma_yy sigma_xy
  --arbitrary sigma_xx sigma_yy sigma_zz sigma_xy sigma_yz sigma_xz
                        Evaluate an arbirtary stress point specified in Voce
                        convention: sigma_xx sigma_yy sigma_zz sigma_xy
                        sigma_yz sigma_xz
  --yld theta_begin theta_end theta_step
                        Calculate yield locus characteristics
  --version             show program's version number and exit
  --serial              Force serial execution of the workflow
  --intermediate_dir directory_path
                        Working directory where intermediate results are
                        produced
\end{DoxyVerb}
\hypertarget{page_simple_mode_vef_confgen}{}\doxysection{vef\+\_\+confgen}\label{page_simple_mode_vef_confgen}
The {\ttfamily vef\+\_\+confgen} tool simplifies the batch execution of multiple VEF analysis for the same material input data. You can try this tool on the examples included in the distribution\+: {\ttfamily examples/confgen\+\_\+sid1687f.\+yaml} and {\ttfamily confgen\+\_\+\+AKDQ.\+yaml}. \begin{DoxyVerb}usage: vef_confgen [-h] --input INPUT [--output_prefix OUTPUT_PREFIX]
                       [--input_texture INPUT_TEXTURE] [--quiet]

Generate alamDMC configuration files from YAML job specification

The purpose of the tool is to run various types of VEF simulations for
the same basic settings (texture data, hardening etc.).

optional arguments:
  -h, --help            show this help message and exit
  --input INPUT         YAML job specification file
  --output_prefix OUTPUT_PREFIX
                        prefix for the output files. It overrides the settings
                        in the YAML file.
  --input_texture INPUT_TEXTURE
                        path to the input texture file (SMT). Overrives the
                        setting in the YAML file.
  --quiet               suppress the terminal output
\end{DoxyVerb}
