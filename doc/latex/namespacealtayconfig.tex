\doxysubsection{Detailed Description}
Provides configuration data for Al\+Tay. 

\begin{DoxyRemark}{Remarks}
The module is derived from the module alamel\+Config, taken from the alamel\+Sub project. However, the differences in the API are drastic. For this reason, the API is intentionally made even more incompatibile (e.\+g. changes in the names of datastructures) to force the users of the alamel\+Sub to make a deliberate, conscious and well-\/thought decision of upgrading their code to the altay\+Sub. Basic configuration of Al\+Tay in a form of formalized data structures. 
\end{DoxyRemark}
