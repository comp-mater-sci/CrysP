\hypertarget{guided_tour_gt_introduction}{}\doxysection{Introduction}\label{guided_tour_gt_introduction}
Throughout this guided tour, we will walk you through the the most common VEF features. This guided tour is written for the \mbox{\hyperlink{page_expert_mode}{expert mode}} that provides the most elaborate control over the virtual experiments.\hypertarget{guided_tour_autotoc_md36}{}\doxysubsection{Expert mode -\/ what\textquotesingle{}s that?}\label{guided_tour_autotoc_md36}
The VEF consists of a number of programs. One of these, the {\ttfamily alam\+DMC} program, is the corner stone, since it carries out most of the computational work. In this guided tour we will primarily demonstrate how to use {\ttfamily alam\+DMC} and how to interpret its results. We call it \char`\"{}expert mode\char`\"{} because it comes down to writing configuration files and running programs from a command line (command prompt on Windows or user shell on Linux).\hypertarget{guided_tour_autotoc_md37}{}\doxysubsection{Let\textquotesingle{}s start!}\label{guided_tour_autotoc_md37}

Please run the command prompt window and change the directory to {\ttfamily guided\+\_\+tour\+\_\+directory}. The very first thing we have to do is to initialize a VEF session. To do so, we run {\ttfamily vef\+\_\+session} command from the VEF installation directory. For instance, if the VEF is installed in {\ttfamily c\+:\textbackslash{}\textbackslash{}VEF}, the command is\+:

\hypertarget{guided_tour_gt_input_texture}{}\doxysection{Input texture}\label{guided_tour_gt_input_texture}
The VEF calculations require crystallographic texture data as input. The texture is usually provided as the Orientation Distribution Function (ODF), either in the form of a continuous function or as OFD intensities on a regular grid. Before we use the texture data in the VEF software, we have to make a discrete ODF by sampling orientations from the ODF ~\newline
 to get a collection of discrete orientations, which as a whole approximates the input ODF. In this example we are going to start from the ODF exported from MTEX Toolbox \textbackslash{}opcite\{MTEX\}.

\begin{DoxyNote}{Note}
The VEF currently supports importing texture data from MTEX. ~\newline
 However, the data must satisfy two requirements\+: triclinic symmetry must ~\newline
 be pre-\/imposed and Bunge convention has to be used. Please see \href{https://mtex-toolbox.github.io/files/doc/ODFImportExport.html\#7}{\texttt{ MTEX documentation}} how to export ODF data to generic ASCII files.
\end{DoxyNote}
Let us use the texture data for a ferritic steel (it\textquotesingle{}s DX51D, for your curiosity), given in the file {\ttfamily sid1687f.\+odf}. It so happens the texture is expressed in the \mbox{\hyperlink{page_conventions_convention_reference_frame}{material reference frame}} where the RD, TD and ND are the first, second and third axis, respectively. By the way, this reference frame adheres to a pretty common convention used in measuring texture of rolled alloys. If you wish, you can first inspect the texture by plotting a set of ODF sections. To do so, run the \mbox{\hyperlink{page_utilities_odfplot}{odfplot command}}\+: 
\begin{DoxyPre}
odfplot -\/-\/input sid1687f.odf -\/-\/sections 0,45 -\/-\/style=filled -\/-\/no-\/labels
\end{DoxyPre}


This will produce two PNG files\+: {\ttfamily sid1687f\+\_\+0.\+png} and {\ttfamily sid1687f\+\_\+45.\+png}\+:     ODF section $ \phi_2 = 0^\circ $      ODF section $ \phi_2 = 45^\circ $ 

As we can see from these ODF sections, the material has a prevalently strong $\gamma$-\/fiber.

Let us now sample the ODF to get representative crystal orientations. As a rule of thumb, we recommend to use at least 2000 (ideally\+: 3000 -\/ 7000) orientations to get a good representation of the macrotexture. The command \mbox{\hyperlink{page_utilities_odf2smt}{\`{}odf2smt\`{}}} will do the sampling\+:

\end{DoxyPre}
