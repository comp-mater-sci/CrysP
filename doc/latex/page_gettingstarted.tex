     When running the installer, they will ask if you want to add Anaconda or Miniconda to your PATH environment variable. We reccomend to let this checkbox unmarked and manually append the change the PATH environment variable with only the strict necessary folders.

To append these folders to your PATH, open start and type \char`\"{}edit the system environment variables\char`\"{}. When you opened the suggested application, you get the system properties screen. At the bottom of this window there is the button \char`\"{}\+Environment Variables\char`\"{}. When clicked it opens a window with the user defined environment variables and the system environment variables. Unless you have administrator rights and want to enable conda python for every user, you should edit the User defined \char`\"{}\+Path\char`\"{} variable. Append the folder \char`\"{}$<$path to anaconda3/miniconda3$>$\textbackslash{}condabin\char`\"{} to this variable. If you already had Anaconda3 or Miniconda3 installed, but this path was not yet added to the environmend variable, you should also do that.
