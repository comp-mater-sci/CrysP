\begin{DoxyEnumerate}

This component of the {\itshape total} stress $\boldsymbol{\sigma}$ is derived from the deviatoric stress tensor $\mathbf{S}$ as\+: \[ \sigma_{xx}=S_{xx}+\sigma_h=S_{xx}-S_{zz} \] in which the hydrostatic stress $ \sigma_h $ is derived from the assumption that the sample is stress-\/free along the z-\/axis\+: $ \sigma_{zz}=S_{zz}+\sigma_h=0 $.

\item \textbackslash{}outdef\{dotW\} The rate of plastic work $ \dot{W} $ 


\item \textbackslash{}outdef\{M-\/factor\} The volume-\/average Taylor factor $ \overline{M} $

It is obtained from volume-\/averaging the sum of microscopic slip rates over all deformation systems $ \dot{\gamma} $, as \[ \overline{M}= \frac{\overline{ \dot{\gamma} }}{D_{vM}} \] The von Mises equivalent strain rate $ D_{vM}=\sqrt{2/3} \| \mathbf{D} \| $ is used as normalization factor.

It is defined as \[ q_i = \frac{-D_{yy}}{D_{xx}} \] where $D_{yy}$ and $D_{xx}$ are the strain rates in the width and tensile directions, respectively. It relates to the instantaneous r-\/value as $ q_i = \frac{r_i}{1+r_i} $.

\item \textbackslash{}outdef\{q-\/valueA\} The (strain-\/based) q-\/value $ q $

It is defined as \[ q = \frac{-\epsilon_{yy}}{\epsilon_{xx}} \] where $\epsilon_{yy}$ and $\epsilon_{xx}$ are the strains in the width and tensile directions, respectively. It relates to the r-\/value as $ \displaystyle q = \frac{r}{1+r} $. 


\item \textbackslash{}outdef\{r-\/valueA\} The (strain-\/based) r-\/value $ r $

It is defined as\+: \[ r = \frac{\epsilon_{yy}}{\epsilon_{zz}} \] where $\epsilon_{yy}$ and $\epsilon_{zz}$ are the strains in the width and thickness directions, respectively. It relates to the q-\/value as $ \displaystyle r = \frac{q}{1-q} $.

The Arbitrary Deformation Path prescribes an arbitrary generic deformation on a virtual sample. Several subsequent deformation {\itshape steps} may be imposed; each step imposes a certain (constant) deformation. The module can also be used to simply calculate stress response of the virtual sample to a superimposed deformation. All inputs and outputs are reported in the global material frame.

\begin{DoxyNote}{Note}
This module implements a deformation-\/driven crystal plasticity model. The only available option in \mbox{\hyperlink{page_alamdmc_generic_config_search_procedure}{Configuration of the search procedure}} is to use the default settings.
\end{DoxyNote}

\end{DoxyItemize}
\item \textbackslash{}confdef\{update\+\_\+state,logical,update\+\_\+state\+\_\+\+ADP\} controls updating the material state in the given step. When set to\+:
\begin{DoxyItemize}
\item {\ttfamily False} then the stresses and other outputs are queried without finite deformation and without associated evolution of state.
\item {\ttfamily True} then the deformation is actually imposed, resulting in evolution of state.
\end{DoxyItemize}
\item \textbackslash{}confdef\{incrementation\+\_\+type,string,incrementation\+\_\+type\+\_\+\+ADP\} specifies how the deformation increments will be calculated. Possible values are\+:
\begin{DoxyItemize}
\item {\ttfamily none}

The step will not involve any incrementation, but the prescribed deformation will be imposed in a single increment.

\begin{DoxyNote}{Note}
This option is often used in a combination with disabled updating of material state.
\end{DoxyNote}

\item {\ttfamily auto}

If this option is used, the module will attempt to automatically determine a suitable incrementation. In general, it will try to avoid large increments.
\item {\ttfamily fixed}

If this option is used, it is followed by a multi-\/line suboption of \mbox{\hyperlink{page_alamdmc_format_range_option}{the compound datatype \`{}realrange\`{}}} that allows the user to specify how the step deformation is subdivided into strain increments. The range of values provides the relative positions of the increment ends on a normalized total step size. The values 0.\+0, which corresponds the beginning of the step, and 1.\+0, which correspond to its end, are assumed and the user does not need to specify them.

The values in the range must be\+:
\begin{DoxyItemize}
\item larger than 0. and smaller than 1., and
\item given in a strictly increasing order.
\end{DoxyItemize}
