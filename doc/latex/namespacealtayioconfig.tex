\doxysubsection{Detailed Description}
This module contains the configuration parameters of IO operations as well as other IO-\/related entities, such as IO unit numbers. 

\begin{DoxyNote}{Note}
The module replaces /\+ES/ and /\+ES1/ common blocks and a subset of /\+TEXTUR/ block. 
\end{DoxyNote}
