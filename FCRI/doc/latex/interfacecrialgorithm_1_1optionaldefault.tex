\doxysubsection{Detailed Description}
Test the presence of optional value, and return a default if the optional is not present. 

The function provides a simplified access pattern to optional parameters. The first formal argument is declared as optional parameter, butit must always appear as the actual parameter in a context where the actual parameter is declared itself as \char`\"{}optional\char`\"{}.
